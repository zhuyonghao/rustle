# Rustle

将视频与音频整理成可阅读、可行动的笔记。原生 macOS 桌面应用，使用 SwiftUI、AVFoundation 与开源 whisper.cpp，要求 macOS 14 或更新版本。

## 下载安装

前往 [GitHub Releases](https://github.com/zhuyonghao/rustle/releases/latest) 下载最新安装包。当前预编译版本适用于 Apple Silicon（M 系列芯片），要求 macOS 14 或更新版本；Intel Mac 可从源码构建。

下载 `.dmg` 后打开，将 `Rustle.app` 拖入「应用程序」；也可下载 `.zip` 解压后复制应用。发布页同时提供 `SHA256SUMS.txt` 校验文件。应用内含本地 Whisper 运行程序，不包含识别模型；首次使用时在设置中下载或选择模型。

当前安装包使用临时签名，尚未使用 Developer ID 签名或经过 Apple 公证，首次打开可能被 macOS 安全机制拦截。已知问题与验证结果见各版本发布说明。

## 界面

采用 macOS 原生窗口工具栏和可调整宽度的侧边栏，左侧为记录列表，中间为内容洞察，右侧为记录信息、播放器与转写文稿，配色跟随系统浅色 / 深色模式与强调色。记录列表支持键盘选择，搜索框、文稿分段切换、播放进度和待办复选框使用系统控件。按 `⌥⌘I` 显示或隐藏右侧转写文稿。

## 功能

- 导入本地视频、音频或可直接下载的媒体链接。
- 使用麦克风边录边转写，实时显示录音时长、输入音量和带时间戳的分段文稿，结束后保存完整录音。
- 中间区域可切换「内容洞察」和「我的笔记」。笔记支持 Markdown 所见即所得编辑、自动保存和独立 `.md` 导出。
- 生成带时间戳的转写，完成后自动生成摘要、关键要点与思维导图。
- 思维导图按分支配色，侧栏支持逐级或一键展开 / 收起；独立窗口支持居中查看、双指缩放、自动适应窗口与完整高清 PNG 导出，配色跟随系统外观。
- 点击生成待办、围绕原文追问、翻译字幕并导出 SRT；各功能结果独立保存。
- 收藏记录、搜索内容、勾选待办与导出笔记。
- 在工具栏点击删除按钮、右键记录选择「删除记录及内容…」，或按 `⌘⌫`，确认后删除记录及全部文稿、内容洞察和本地媒体副本；原始文件保留。删除处理中的记录会取消当前导入批次。
- 默认在本机运行开源 Whisper 模型，支持 Metal 加速与 CPU 模式，无需上传音视频。
- 可选阿里云百炼 ASR 转写；内容洞察使用单独配置的 OpenAI 兼容 API。
- 内置示例内容，可先体验界面再配置服务。

链接导入支持直接返回音视频文件的 HTTP/HTTPS 地址，下载文件上限为 500 MB。安装可选的 `yt-dlp` 后，也可以尝试该工具支持的公开视频播放页面；网站限制、登录要求、格式兼容性或 DRM 可能导致导入失败。平台链接导入后自动使用视频标题作为记录名称；媒体直链使用服务器提供的文件名。

## 实时转录

点击「实时转录」或按 `⇧⌘R`，检查当前识别配置并允许麦克风权限后开始录音。使用系统当前的默认输入设备，仅采集麦克风，不采集系统播放声音。完整音频保存为记录目录内的 `microphone.caf`；每约 5 秒将已关闭的音频分段依次交给当前配置的识别服务，识别后追加到文稿。文字显示会有采集与识别延迟：本地模型越大或设备越慢，等待时间可能越长。录音时可查看持续追加的文稿，结束后点击时间戳跳转播放。

选择本地 Whisper 时，录音在本机识别；选择百炼时，分段录音会上传到已配置的 ASR 服务并产生用量。转写完成后沿用现有流程自动生成摘要和思维导图，文字会发送给单独配置的内容整理 API。实时转录不会修改当前服务配置。

点击「结束录音」立即停止采集，补齐不足 5 秒的尾段，并继续完成排队中的识别；「停止剩余转写」可取消等待，保留完整录音和已识别文字。权限拒绝不会创建空记录。识别失败、输入设备变化或退出应用时停止录音，保留已保存内容；失败记录可点击「重新转写」用保存的完整录音重试。重试成功才替换文稿并更新 AI 洞察。录音和剩余转写期间不能同时导入媒体或迁移存储位置；仍可浏览其他记录。删除正在录音的记录会先停止麦克风与识别，再清理其本地音频。

## Markdown 笔记

选择记录后，在中间切换到「我的笔记」即可编辑。正文直接显示排版效果，支持标题、加粗、斜体、删除线、行内代码、无序 / 有序 / 待办列表、引用、代码块、表格和链接。可使用格式工具栏、`⌘B` / `⌘I` 等快捷键，或输入 `# `、`- ` 等 Markdown 标记；粘贴 Markdown 时自动解析为可编辑内容。待办复选框可直接勾选，表格支持添加行列；撤销 / 重做和当前选区在切换中间页签时保留。按住 `⌘` 点击链接可在浏览器打开。

笔记以 Markdown 保存到本机资料库，停止输入 350 毫秒后自动保存，切换记录不会覆盖另一条记录的笔记。底部显示保存状态；写入失败时保留草稿并提供「立即保存」。修改笔记不影响转写、已有内容洞察和正在进行的实时转录，修改转写也不清空手写笔记。笔记内容参与资料库搜索。

点击笔记页右上角「导出 Markdown」导出独立 `.md` 文件，保留正文中的 Markdown 格式，不附加转写、摘要或额外标题。工具栏中的整条记录 Markdown 导出也会保留笔记格式；SRT 仅导出字幕。工具栏不额外添加新建笔记按钮。

编辑器基于 Tiptap / ProseMirror，脚本、样式和第三方许可随应用打包，编辑和导出不需要 Node.js、API 或 CDN。笔记中的 HTTPS 图片在显示时会按链接加载，点击外部链接会打开默认浏览器。仅在修改编辑器前端源码时需要 Node.js：

```sh
cd web/notes-editor
npm ci
npm test
npm run build
```

前端源码与依赖锁定文件位于 `web/notes-editor/`，已打包资源位于 `Sources/Rustle/Resources/NotesEditor/`。更新后将源码与生成资源一起提交，常规 Swift 构建直接使用已打包资源。

## 构建和运行

安装 Apple Command Line Tools 即可，无需完整 Xcode、Node.js 或 FFmpeg。首次安装 ASR 需要下载源码、构建工具和模型，后续本地转写可离线运行。

```sh
xcode-select --install

# 安装本地 whisper.cpp 与多语言 base 模型
./scripts/setup-local-asr.sh base

# 构建调试版并打开桌面应用
./scripts/run.sh

# 构建发布版
./scripts/build-app.sh release

# 核心测试（仅安装 Command Line Tools 也可以运行）
./scripts/test-core.sh

# 使用真实本地模型识别官方 JFK 样例（先安装 ASR）
./scripts/test-local-asr.sh
RUSTLE_TEST_GPU=1 ./scripts/test-local-asr.sh

# 安装完整 Xcode 后，也可使用 XCTest
swift test
```

应用生成在 `dist/Rustle.app`，可以通过 Finder 打开或复制到「应用程序」。本地 Whisper 运行程序会自动打包进应用，识别模型默认不打包；请在设置中下载或选择已有模型。`./scripts/run.sh release` 可构建并启动发布版。源码运行时可在设置中选择项目 `.runtime/models/` 中的模型。

## 本地开源 ASR

### 运行环境检测

打开设置后会自动检测 macOS 版本、记录目录读写、本地 Whisper 程序启动与所需参数、模型文件头及识别语言匹配，并检查可选的 `yt-dlp` 是否能够运行。可点击「重新检测」刷新；切换识别服务、运行程序、模型或语言后自动重新检查。缺失或异常项会显示修复方法，可直接选择文件、打开模型下载窗口或复制可选工具的安装命令。检测不安装软件、不上传媒体、不请求 API。

导入前会重新检查必需环境，未就绪时打开设置，不创建失败记录或复制媒体。百炼 ASR 跳过本地 Whisper 检查；缺少 `yt-dlp` 不影响本地文件和媒体直链。模型检测仅验证可读性和文件头，不代替下载时的完整性校验；GPU 推理、网络、API 密钥及额度仍以实际处理结果为准。

在「设置 → 本地存储」可查看并更改存储位置。选择一个文件夹后，应用在其中新建 `Rustle` 子目录，将记录库、媒体、已下载模型和密钥复制过去，成功后立即切换并记住位置；原目录保留作为备份。新目录已存在时不会覆盖或合并，复制失败仍使用原位置。录音、转写、导入、内容生成和模型下载期间不能切换。`RUSTLE_DATA_DIR` 环境变量优先于设置中的位置，使用该变量时需修改环境变量后重新启动。

识别模型可直接通过下拉列表切换：列表包含已下载、应用内置和检测到的本地模型；选择外部模型后也会列出同目录中的其他 `.bin` 模型。未保存模型选择时，启动会按内置优先级默认选择本机已安装的最强多语言模型，优先使用 Large v3 完整模型；没有可用模型时显示「请选择模型」。模型下载页默认选中 Large v3。已保存的手动选择保持优先，指定文件失效时提示修复。仍可通过 `RUSTLE_WHISPER_MODEL` 环境变量显式指定模型。保留刷新列表和选择其他模型文件的入口。下拉选择在当前会话立即生效，点击「保存设置」后记住选择。

使用 [whisper.cpp](https://github.com/ggml-org/whisper.cpp) 的固定版本 v1.9.5，源码与构建工具保存在项目 `.runtime/` 内，不修改系统 Python 或 Homebrew。安装脚本下载并校验官方 GGML 模型；默认多语言 base 模型约 142 MiB。可将脚本参数改为 `tiny`、`small`、`medium`、`large-v3` 或 `large-v3-turbo`，以权衡速度、内存与准确度。

在设置中选择 `本地 Whisper · 开源`，检查运行程序与模型显示为就绪。中文需使用多语言模型，不能使用仅支持英语的 `.en` 模型。音轨由 AVFoundation 转换为 16 kHz、单声道、16 bit WAV，导入文件按十分钟分段本地识别，再合并时间戳。导入转写无需麦克风或系统语音识别权限，实时录音需要麦克风权限。此版本未实现说话人身份识别，实际转写统一标为“发言人”。

选择其他模型后可在设置中指定 `.bin` 文件。也可通过 `RUSTLE_WHISPER_EXECUTABLE` 和 `RUSTLE_WHISPER_MODEL` 环境变量配置；显式指定的文件失效时会报错，不会静默替换为其他模型。仅在确实需要制作含模型的专用包时，显式设置 `RUSTLE_BUNDLE_MODEL=1 RUSTLE_WHISPER_MODEL=/完整路径/ggml-small.bin ./scripts/build-app.sh release`；普通构建不包含模型。

中文使用可优先尝试 `small` 模型；模型通过设置下载或选择，保存在应用包之外。识别准确度仍受录音质量、口音及模型大小影响，文稿可直接编辑；需要更高准确度时可切换更大模型。`zh-CN` 结果会转换为简体中文。

## 阿里云百炼 ASR

在「设置 → 语音转写 → 识别服务」中选择「阿里云百炼 ASR」。默认模型为 `qwen-audio-3.0-asr-flash`，转写 API 地址为 `https://dashscope.aliyuncs.com/api/v1`。填写百炼 API Key；如果内容整理已经使用百炼，可点击「使用内容整理中的百炼密钥」填入，再保存设置。语音转写和内容整理仍分别保存配置。切换云端识别服务时会清空当前转写密钥，避免将其他服务的密钥发送给新服务。

该模型使用百炼原生 `services/aigc/multimodal-generation/generation` 接口，与 Whisper 的 `audio/transcriptions` 接口不同。程序提取 16 kHz 单声道 WAV，通过 Base64 提交，长音频自动按 3 分钟分段，以满足编码后 10 MB 的请求限制；会上传音轨并产生服务商用量。服务返回的 SSE 最终句子按编号去重，毫秒时间戳转换为秒后合并到原始媒体时间轴。词级结果包含完整原文时按标点或约 12 秒拆分字幕，否则保留完整句子及其时间戳。未完成结果或无效时间戳不会作为成功转写保存。接口依据[阿里云官方文档](https://help.aliyun.com/zh/model-studio/fun-asr-flash-recorded-speech-recognition-http-api)。

部分结果会以不同句子编号返回从同一时刻开始的累计前文；程序合并这些最终快照，再按实际词时间戳排列字幕，避免重复与时间倒退。在不同时间真正重复说出的文字会保留。打开已有记录时会修复同一时间、同一发言人的重复或扩展段落，并保存原始记录库备份 `library-before-timeline-repair-*.json`，无需重新请求识别服务。

## 模型下载与下载源

在「设置 → 开源本地模型 → 管理与下载模型」中选择模型与下载源。支持 [Hugging Face 官方模型仓库](https://huggingface.co/ggerganov/whisper.cpp/tree/main)、[HF Mirror 第三方镜像](https://hf-mirror.com/) 和自定义地址。内置源可以在连接失败或校验失败时切换到另一源；自定义源不自动切换。

下载窗口显示实际已下载字节和进度，支持取消与重试。下载完成后会流式计算 SHA-1，与 whisper.cpp v1.9.5 公布的校验值比较；仅校验通过才安装并切换模型，失败时保留当前模型。已下载模型保存在 `~/Library/Application Support/Rustle/Models/`。关闭下载窗口不会中断任务，退出应用会取消下载；重新尝试会从头下载。

自定义地址可以填写下载直链、模型所在目录，或使用 `{filename}` 模板，例如 `https://example.com/models/{filename}`。自定义源须提供与所选官方 GGML 模型相同的文件。下载模型不发送你的音视频或文稿。

命令行安装也支持切换来源：

```sh
./scripts/setup-local-asr.sh small hf-mirror
RUSTLE_MODEL_SOURCE=huggingface ./scripts/setup-local-asr.sh base
RUSTLE_MODEL_URL='https://example.com/models/{filename}' ./scripts/setup-local-asr.sh small custom
# 禁用备用下载源
RUSTLE_MODEL_FALLBACK=0 ./scripts/setup-local-asr.sh small hf-mirror

# 实际下载 Tiny 模型，验证下载源、字节进度和完整性（需要联网）
./scripts/test-model-download.sh hf-mirror tiny
```

本地文件与媒体直链不依赖外部下载器。若需要尝试视频网站页面，可通过 Homebrew 安装 `yt-dlp`：`brew install yt-dlp`。

导入链接时，平台解析、下载、提取音轨和转写分别显示当前阶段。下载展示真实字节进度、速度和预计剩余时间；服务器未提供总大小时仅显示已下载大小。本地 Whisper 使用 `-pp` 的实际识别进度，展示已处理时长及十分钟分段数；模型加载期间显示等待状态和已用时间。API 转写服务未提供段内进度时明确显示等待，仅在分段完成后更新比例。取消后会停止网络或本地进程，旧回调不会覆盖下一阶段。

可验证真实链接的下载与本地 small 转写进度（需安装 yt-dlp 与 small 模型）：

```sh
./scripts/test-media-progress.sh 'https://www.bilibili.com/video/BV1LSLi6zEoK'
```


脚本会生成应用图标并进行本机临时签名。对外正式分发仍需 Developer ID 签名和 Apple 公证。

## 识别服务与隐私

本地 Whisper 转写在设备上运行，音视频不会上传。内容整理会将转写后的文字发送到你配置的 API。媒体需包含 macOS 能解码的音轨；不兼容时可先转为 MP3、M4A、WAV 或 MP4。

内容洞察仅使用 API。转写完成后自动生成概览（摘要与关键要点）和思维导图；待办仅在点击该功能后提取，追问在发送问题后生成回答，SRT 翻译在选择目标语言并点击生成后调用。打开已有记录或切换已生成的功能不会重复请求。整理服务使用 OpenAI 兼容 API，默认地址为 `https://api.openai.com/v1`，模型为 `gpt-4o-mini`，使用 JSON Mode。服务地址、模型和 API Key 均可在「设置 → 内容整理 · 仅 API」中修改，可填写百炼等兼容服务的地址和模型。语音转写仅提供本地 Whisper 与阿里云百炼；已移除通用兼容 API 转写和 Kimi 专用整理选项。旧版选中已移除服务的配置会回退到默认值并清空对应的当前密钥，需重新配置后保存；已有兼容整理服务和百炼转写配置保留。

内容整理 API 与语音转写 API 分别配置，密钥以明文保存在 `~/Library/Application Support/Rustle/Credentials/api-keys.json`，不进入源码、普通偏好设置或记录库。密钥目录权限为 `0700`，文件权限为 `0600`，限制其他 macOS 账户访问；这不提供加密保护。同一文件同时保存两项密钥，保存采用原子替换，清空两项密钥并保存会删除该文件。应用不再读取或写入系统钥匙串，也不会自动迁移旧钥匙串条目；从旧版升级后需在设置中重新填写并保存密钥，旧条目可在「钥匙串访问」中手动删除。使用 `RUSTLE_DATA_DIR` 时，密钥随记录库保存在指定目录下，请勿将此目录提交到版本库或共享。使用本地 Whisper 时只将文稿发送给内容整理服务。若选择 API 语音转写，则音频会发送到单独配置的转写服务。API 调用可能产生服务商费用。

缺少整理密钥、网络故障、额度不足或格式不正确时，显示可重试的错误，保留转写文稿，不生成替代摘要或待办。每个功能可以单独重试，生成失败时保留上一次有效结果。内容整理使用流式输出，边生成边显示文字，完成校验后保存正式结果；兼容服务若返回普通 JSON，则在完整返回后显示。不同功能与不同记录的 API 请求独立并发，自动摘要和思维导图同时开始；同一记录的同一功能生成期间不重复请求。取消仅停止当前功能，编辑文稿或删除记录会取消该记录的全部生成任务，其他请求继续运行。思维导图支持展开与收起分支；点击「放大查看」可在独立窗口中以 10%–300% 缩放、滚动查看，支持适应窗口和恢复原始大小。点击「导出图片」可保存 2 倍分辨率的 PNG，始终包含全部分支，不受收起状态、窗口大小或缩放比例影响。生成时显示处理阶段和已用时间；每次内容整理 API 请求最多等待 3 分钟。导图兼容叶子节点省略或返回 null 的 children；返回格式或层级不符合要求时自动修正一次，仍失败则显示具体原因并允许重试。追问参考原文与最近六轮对话。SRT 翻译支持简繁中文、英语、日语、韩语、法语、德语与西班牙语，译文沿用原始字幕的编号和时间轴。按字幕条数与文字长度分批翻译并显示当前进度；兼容 JSON 代码围栏及字符串形式的整数编号，格式、漏条或编号错误时自动纠正一次，输出被截断时拆成更小批次。临时限流最多自动重试两次并遵循 Retry-After（等待超过 60 秒时提示稍后重试），明确的额度不足与鉴权失败直接提示；等待期间可取消。编辑文稿后清除旧洞察，避免继续使用过期结果。已移除规则摘录功能；升级时清除非示例记录的旧摘录，保留文稿、媒体及已有 API 结果，升级前的记录库备份为 `library-before-api-insights.json`。示例内容仍为静态演示，不会自动调用服务。

记录库和导入媒体副本保存在 `~/Library/Application Support/Rustle/`，密钥单独保存在该目录下的 `Credentials/` 中。应用不会修改导入的原文件。

快捷键：`⇧⌘R` 开始 / 结束实时录音，`⌘O` 导入音视频，`⌘L` 导入媒体链接，`⌘⌫` 删除当前记录及内容（需确认，也可通过「编辑」菜单操作），`⌘,` 打开设置。
